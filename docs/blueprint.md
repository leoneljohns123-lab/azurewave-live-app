# **App Name**: AzureWave Chat

## Core Features:

- Real-time Messaging: Send and receive text messages in real time within chat rooms.
- Public Chat Room Creation: Users can create public chat rooms with different topics.
- Chat Room Listing and Joining: Browse a list of available chat rooms and join existing rooms.
- User Profiles: Create and manage simple user profiles.
- Live User List: View a list of currently online users in each chatroom.

## Style Guidelines:

- Primary color: Soft blue (#A0D2EB) to evoke calmness and friendliness.
- Background color: Very light blue (#F0F8FF), nearly white, for a clean, open feel.
- Accent color: A slightly darker blue (#7CB9E8), for interactive elements.
- Font: 'PT Sans' (sans-serif) for both headlines and body text to maintain a friendly and approachable feel.
- Use simple, outlined icons for chat actions and room navigation.
- Design a clean and intuitive layout with clearly defined sections for chat rooms, messages, and user lists.
- Incorporate subtle animations for new messages and user joins to provide gentle feedback.
